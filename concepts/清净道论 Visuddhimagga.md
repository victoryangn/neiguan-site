# 清净道论 Visuddhimagga
> Visuddhimagga（清净道论）——5世纪[[觉音 Buddhaghosa|觉音]]造的上座部禅修百科全书，南传佛教禅修理论的集大成之作。它以「**七清净**」为骨架，系统组织[[戒定慧三学]]从持戒到证果的完整次第，并详述[[止禅 Samatha|止禅]]、四十业处与十六观智，是内观传承理论框架的直接来源。

## 核心含义

「Visuddhi」（清净）+「magga」（道/路径）——即「通达清净之道」。全书以「清净」这一概念贯穿：修行者从染污的凡夫，经戒、定、慧七个层次的清净，逐步净化，最终证[[解脱阶段|圣果]]。《清净道论》之名即点明：这是一条以「清净」为标尺的修行道次第。

## 七清净骨架

这是全书的脊椎，对应戒定慧三学的展开：

| 七清净 | 巴利语 | 对应 | 本 Wiki |
|--------|--------|------|---------|
| 一、戒清净 | Sīla-visuddhi | 戒学 | [[五戒与戒律]]·[[戒定慧三学]] |
| 二、心清净 | Citta-visuddhi | 定学 | [[止禅 Samatha]]·[[禅那 Jhana]] |
| 三、见清净 | Diṭṭhi-visuddhi | 慧学·初阶 | 见名色，破我见 |
| 四、度疑清净 | Kaṅkhāvitaraṇa-visuddhi | 慧学 | [[缘起 Paticca Samuppada|把握缘起]] |
| 五、道非道智见清净 | Maggāmagga-ñāṇadassana | 慧学·中阶 | 辨真道与十随观之歧途 |
| 六、行道智见清净 | Paṭipadā-ñāṇadassana | 慧学·深阶 | 生起诸观智，趣向圣道 |
| 七、智见清净 | Ñāṇadassana-visuddhi | 慧学·究竟 | 证[[解脱阶段\|四道四果]] |

> 前二清净（戒、心）即戒定，后五清净即慧（观）的层层深入。它把「戒→定→慧」这条抽象次第，细化为可操作的七个清净阶段。

## 全书结构

《清净道论》共二十三品，依「戒 → 定 → 慧」三大部分组织：

- **戒品**（第1品）：论述戒的种类、持戒功德——戒清净。
- **定品**（第2–11品）：[[止禅 Samatha|四十业处]]的修法、得定与[[禅那 Jhana|禅那]]、神通——心清净。
- **慧品**（第12–23品）：如实知蕴、处、界、根、谛、缘起（见清净、度疑清净），生起十六观智（道非道、行道智见清净），证四道四果（智见清净）。

### 十六观智

慧品后半详述观智（ñāṇa）的生起次第，是南传内观「智」的理论框架：

```
1.名色分别智 → 2.缘摄受智 → 3.思惟智（三相）
→ 4.生灭随观智 → 5.坏灭随观智 → 6.怖畏现起智
→ 7.过患随观智 → 8.厌离随观智 → 9.欲解脱智
→ 10.审察随观智 → 11.行舍智 → 12.随顺智
→ 13.种姓智 → 14.道智 → 15.果智 → 16.省察智
```

> 从「名色分别」（见到身心真实成分）到「种姓智」（转入圣者）到「道智、果智」（证果），构成内观智慧的完整生起次第。其中第4「生灭随观」、第5「坏灭随观」对应内观传承所强调的[[内观 Vipassana|消融（bhanga）]]体验。

## 地位与影响

- 《清净道论》与稍早的《解脱道论》（Vimuttimagga，Upatissa 造）是南传禅修理论的两大古典，前者由觉音集大成而成为权威。
- 它将[[阿毗达磨 Abhidhamma|阿毗达磨]]的法相分析与实修次第打通——阿毗达磨提供「地图」，清净道论提供「路径」。
- [[乌巴庆 Sayagyi U Ba Khin]] → [[葛印卡 S.N. Goenka]]的内观传承，其「七清净」「十六观智」的理论框架，根植于觉音此书所整理的传统（尽管课程实践不强调理论名相）。
- 北传在禅修道次第上，则有世亲《俱舍论》（法相）、宗喀巴《菩提道次第广论》（待建，藏传显教次第）等并行体系。
