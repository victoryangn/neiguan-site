# 十波罗蜜

**Parami** — 十种圆满美德，是菩萨（Bodhisatta）在无数劫中修行的品质，也是每一位内观修行者在修行道上需要培养的美德。波罗蜜意为"到彼岸"——从痛苦的此岸到达解脱的彼岸。

---

## 十种圆满美德

### 1. 布施 — Dana

**慷慨给予** — 放下对物质和精神的执着。

- 不只是物质的布施，也包括时间的布施、精力的布施、法的布施
- 在课程中：以[[慈悲观 Metta]]将修行的功德与众生分享
- 布施的真义：给予时不求回报，给予后不执着
- 布施是破除"我执"的第一步

### 2. 持戒 — Sila

**道德行为** — 遵守[[戒定慧三学|五戒（Panca Sila）]]。

- 不杀生、不偷盗、不邪淫、不妄语、不饮酒
- 持戒是修行的基础，没有道德就没有真正的修行
- 持戒波罗蜜要求即使面临生命危险也不违犯戒律

### 3. 舍离 — Nekkhamma

**出离** — 放下世俗的执着。

- 不是逃避世间，而是真正理解世间的本质
- 在修行中：放下对禅悦的执着，放下对特殊体验的追求
- 舍离是进入[[内观 Vipassana]]修行的心理基础
- 真正的舍离是放下内心的贪瞋痴

### 4. 智慧 — Panna

**洞察实相** — 亲自体验[[三特性|无常]]的智慧。

- 即修慧（Bhavana-maya panna）
- 通过观察[[感受 Vedana|感受]]的生灭而自然生起
- 智慧波罗蜜超越书本知识，是亲证的洞见
- 是十波罗蜜中的核心

### 5. 精进 — Viriya

**不懈努力** — 持续的修行动力。

- 与[[五力]]中的精进力、[[七菩提分]]中的精进觉支一致
- 正精进：四正勤
- 精进波罗蜜意味着即使遭遇困难也不放弃修行
- 如同[[葛印卡 S.N. Goenka]]老师所教导的：要努力，但不要急躁

### 6. 忍辱 — Khanti

**耐心和宽容** — 以平等心面对一切顺逆境。

- 忍辱不是压抑，而是以智慧理解后的平静
- 在内观中：以[[平等心 Upekkha]]面对剧烈的疼痛、不愉悦的感受
- 忍辱波罗蜜意味着面对批评、误解甚至伤害时仍保持慈悲
- 最难的忍辱：对内在不净烦恼的容忍——不与之斗争，也不投降，只是观察

### 7. 真实 — Sacca

**真实和诚实** — 对自己和他人保持真诚。

- 诚实语：不说妄语
- 更深层的真实：不欺骗自己，如实面对自己的内心状态
- 真实波罗蜜要求：即使是痛苦的真相，也勇敢面对
- 在修行中：如实观察感受，不添加任何虚妄的想象

### 8. 坚决 — Adhitthana

**坚定的决心** — 不动摇的意志力。

- 决定修行后就不退缩，无论遇到什么困难
- 在十日课程中：决定坚持完成整个课程，不中途放弃
- 坚决是其他波罗蜜的保障——有决心才能持续修行
- 如同大地一般稳固的基础

### 9. 慈爱 — Metta

**无私的爱** — 对一切众生的善意和祝福。

- 即[[慈悲观 Metta]]所培养的品质
- 不是情感上的执着，而是基于[[平等心 Upekkha]]的慈悲
- 慈爱的真义：即使对伤害自己的人也能保持善意
- 课程第十天开始练习慈悲观的修习

### 10. 平等心 — Upekkha

**圆满的平衡** — 对一切境遇保持不偏不倚的心。

- 这是十波罗蜜的顶峰
- 不因乐受而执着，不因苦受而厌恶
- 平等心是所有修行品质的总和
- 在[[感受 Vedana|观察感受]]时，平等心是最关键的品质

## 波罗蜜的修行

### 需要无数劫

波罗蜜不是一朝一夕可以圆满的。根据佛教传统：

- 一个修行者需要经历**无数劫（Asankheyya）**来圆满这些品质
- 每一世的生命都是培养波罗蜜的机会
- 内观课程的十天只是一个开始，一个播种
- 真正的修行是日日不断，持续精进

### 波罗蜜在课程中的体现

| 波罗蜜 | 在课程中的体现 |
|--------|---------------|
| 布施（Dana）| 课程完全免费，由旧生捐助维持 |
| 持戒（Sila）| 课程期间严格遵守五戒（甚至八戒、九戒）|
| 舍离（Nekkhamma）| 放下外界联系，专注修行 |
| 智慧（Panna）| 每天的内观实践，体验无常 |
| 精进（Viriya）| 每天超过10小时的禅坐 |
| 忍辱（Khanti）| 面对疼痛和不舒适保持耐心 |
| 真实（Sacca）| 如实观察，不欺骗自己 |
| 坚决（Adhitthana）| 决定完成课程，不动摇 |
| 慈爱（Metta）| 最后一天的慈悲观修习 |
| 平等心（Upekkha）| 对一切感受保持不偏不倚 |

## 波罗蜜之间的关联

十波罗蜜不是各自独立的，它们相互支撑：

```
布施 → 放下执着 → 舍离
持戒 → 道德基础 → 真实
精进 → 持续修行 → 坚决
智慧 → 洞察实相 → 忍辱
慈爱 → 无私关怀 → 平等心
```

正如[[葛印卡 S.N. Goenka]]老师所强调：每一位来到内观课程的修行者，都是因为过去世累积了足够的波罗蜜，才有机会接触到这个方法。珍惜这个机会，持续修行，就是在培养更多的波罗蜜。

## 南传十波罗蜜与大乘六波罗蜜

波罗蜜（pāramī / pāramitā，到彼岸）是两大传承共通的菩萨修行科目，但项目与重心不同：

| | 南传上座部（十波罗蜜） | 大乘（六波罗蜜） |
|--|------------------------|------------------|
| 项目数 | 10 | 6（可展开为10） |
| 核心项 | 平等心 Upekkha（十波罗蜜之顶） | 般若 Prajñā（般若为导） |
| 六项对应 | — | 布施 · 持戒 · 忍辱 · 精进 · 禅定 · 般若 |
| 重心 | 菩萨累劫累积圆满德行 | 以空性智慧贯穿一切善行 |
| 来源 | 巴利《佛种姓经》《行藏》 | 般若系经典、《解深密经》 |

> **共通点**：两者都以「布施、持戒、忍辱、精进、般若」为基础。
> **差异**：南传强调菩萨**历劫圆满德行**（如释迦菩萨以十波罗蜜经无数劫成佛）；大乘强调波罗蜜须与**般若空性相应**——行施而不执着施者、受者、施物三轮（三轮体空），此即大乘「般若波罗蜜多」的独到处。

详见[[佛学体系总览]]与后续大乘相关页（[[菩萨道 Bodhisattva]]、般若波罗蜜多，Phase 3 待建）。
