# 业与行 (Sankhara)
> 心的习性反应是痛苦的根本原因——每个贪爱或瞋恨的反应都在造作业力，以平等心观察感受是灭除旧业的唯一途径。

## 核心含义

Sankhara（行）在佛法中有多种含义，在内观修行的语境中，它主要指**心的习性反应**——对感受产生的贪爱或瞋恨的盲目反应。

### Sankhara 作为习性反应

每一次我们对感受起了反应——喜欢就产生贪爱，不喜欢就产生瞋恨——我们就在造作一个 Sankhara。这个 Sankhara 就是业（Kamma/Karma）——意志行为及其带来的力量。

Sankhara 的特点：
- **盲目性**：习性反应是无意识的、自动的。我们甚至没有意识到自己在反应。
- **积累性**：每一个反应都在加深旧的习性模式，同时创造新的习性模式。
- **潜伏性**：Sankhara 沉淀在心的深处（随眠/Anusaya），等待适当的因缘再次浮现。
- **因果性**：Sankhara 是未来的因——现在的反应会成为未来的痛苦。

### Sankhara 在五蕴中的位置

在 [[五蕴]] 中，行蕴（Sankhara-khandha）是第四个蕴，也是最能造作业力的蕴。它包括所有意志行为、决定、反应——尤其是对感受的贪瞋反应。

### Sankhara 与轮回

在 [[缘起 Paticca Samuppada]] 中，"行"是第二个支——"无明缘行"（Avijja-paccaya Sankhara）。因为有无明（不了解实相），所以我们产生习性反应；这些习性反应推动着生死轮回继续运转。

## 两条法则

### 增生法则（Vaddhamana Dhamma）

> 反应越多，痛苦越多。每个习性反应都在增加 Sankhara 的积累。

这是一个恶性循环：
1. 感受生起 → 习性反应 → 造新的 Sankhara
2. 新的 Sankhara 潜伏在心中
3. 当因缘成熟，潜伏的 Sankhara 浮现为新的感受
4. 对新的感受又产生习性反应 → 又造新的 Sankhara
5. 如此循环不息，痛苦不断增长

这就是轮回的本质——一个不断自我复制的痛苦循环。

### 灭除法则（Patipassaddhi Dhamma）

> 以平等心观察感受，不造新业，旧业浮现消除。

这是解脱的道路：
1. 感受生起 → 以 [[平等心 Upekkha]] 观察，不反应 → 不造新的 Sankhara
2. 因为不造新业，旧的潜伏 Sankhara 失去了滋养
3. 旧的 Sankhara 以感受的形式浮现
4. 继续以平等心观察 → 浮现的旧业被根除
5. 如此持续，Sankhara 越来越少，心越来越清净

> 就像蜡烛的火焰：如果你不给它加蜡和烛芯，它终将熄灭。如果你不给 Sankhara 添加新的反应，它终将被根除。

## 修行实践

### 如何不造新业

1. **觉察感受**：通过 [[内观 Vipassana]] 的练习，培养敏锐的觉知力，能够觉察到身体上每一个微细的感受。
2. **觉察反应**：注意到感受如何引发心的反应——乐受引发贪爱，苦受引发瞋恨。
3. **选择平等心**：在感受和反应之间，选择不反应。保持 [[平等心 Upekkha]]，只是观察感受的生灭。
4. **体悟无常**：时时彻知无常（Sampajanna）——彻知感受在不断生灭，没有什么可执取的。

### 让旧业浮现消除

1. 当你停止造新业时，最表层的 Sankhara 首先浮现为感受。
2. 以平等心观察这个感受，这个 Sankhara 就被根除了。
3. 更深层的 Sankhara 继续浮现。
4. 持续这个过程，层层深入。

这就是为什么内观修行需要时间和持续精进——因为无量劫以来积累了无数的 Sankhara，需要一层一层地消除。

### Sankhara 的四个层次

根据 Goenka 老师的教学，Sankhara 可以分为不同深度：
1. **表层 Sankhara**：最容易被观察到和消除
2. **深层 Sankhara**：需要更深的定力和平等心
3. **更深层 Sankhara**：在长时间密集修行中才能触及
4. **最深层的 Sankhara**：需要持续的修行才能完全根除
