# 中观 Madhyamaka
> Madhyamaka（中观/中道学派）——大乘两大哲学支柱之一，由[[龙树 Nagarjuna|龙树]]（约2–3世纪）创立，以「**一切法空、缘起性空、远离断常二边**」为核心，系统阐发[[空性 Sunyata|空性]]哲学。其名「中观」即「依中道而观」——不落有、无两边，直契缘起性空的实相。

## 核心含义

中观是对[[空性 Sunyata|空性]]的系统化哲学论证。面对部派佛教中「一切法实有」（说一切有部）等自性见，龙树以严密的逻辑，论证**一切法（包括涅槃、佛陀、烦恼等）皆缘起、皆无自性、皆空**，从而显发佛陀缘起的究竟义。

### 八不[[中道]]

龙树《中论》开篇著名的「八不」，总括中观破斥一切戏论的方法：

> 「不生亦不灭，不常亦不断，不一亦不异，不来亦不出。能说是因缘，善灭诸戏论，我稽首礼佛，诸说中第一。」

——龙树《中论》归敬颂

「生、灭、常、断、一、异、来、去」是凡夫对事物最根本的八种概念分别（戏论）。龙树一一破斥：缘起故无生无灭、非常非断、非一非异、无来无去。破尽戏论，即显空性中道。

### 二谛（世俗谛与胜义谛）

中观依二谛组织教理，解决「空」与「有」的张力：

| | 世俗谛（相对真理） | 胜义谛（究竟真理） |
|--|--------------------|---------------------|
| 内容 | 名言、因果、缘起的世间 | 一切法空、无自性 |
| 作用 | 凡夫共许的方便 | 般若亲证的实相 |
| 关系 | 「若不依俗谛，不得第一义」 | 藉世俗谛为桥梁，悟入胜义空性 |

> 二谛并非两个世界，而是同一现象的两种观照维度。中观「**缘起有**（世俗）」与「**自性空**（胜义）」并行不悖。

### 破而不立（应成方法）

中观派有一鲜明方法论：**自己不立任何自性主张，唯以对方所许的前提推出矛盾（应成 prasaṅga）来破斥他宗**。因为「立」一个主张本身就有堕入自性见的危险；唯有「破」尽一切执著，空性自然显露。这被称为「破邪即显正」。

## 中观派的传承与分流

```
龙树（Nāgārjuna，创立）
   ↓
提婆（Āryadeva，继承）
   ↓
……（数传）……
   ↓
┌───────────────┬────────────────┐
│ 佛护           │ 清辨             │
│（Buddhapālita）│（Bhāvaviveka）   │
│ 应成派雏形     │ 自续派           │
│                │ （立自宗比量）   │
│   ↓            │                  │
│ [[月称 Candrakirti|月称]]           │                  │
│（Candrakīrti） │                  │
│ 应成派集大成   │                  │
└───────────────┴────────────────┘
```

- **应成派（Prāsaṅgika）**：佛护创、[[月称 Candrakirti|月称]]集大成。坚持「唯破不立」，认为连「自续比量」（自立论证）也预设了自性。藏传格鲁派[[宗喀巴 Tsongkhapa]]依此为究竟。
- **自续派（Svātantrika）**：清辨创。主张可以自立逻辑论证（比量）来成立空性，只要论证本身亦不执自性。

藏传佛教极度重视中观的应成/自续之辨，是格鲁派教理核心。

## 中观与唯识：大乘两大支柱

| | 中观（Madhyamaka） | [[唯识 Yogacara\|唯识]]（Yogācāra） |
|--|--------------------|--------------------------------------|
| 核心命题 | 一切法空、无自性 | 万法唯识所现（三界唯心） |
| 破执重心 | 破「法执」（外境实有） | 先破外境，归于一心，究竟识亦空 |
| 代表 | 龙树、提婆、[[月称 Candrakirti|月称]] | [[世亲 Vasubandhu\|无著]]、世亲 |
| 关系 | 并称大乘二大车轨，时有诤论，究竟同归空性 | |

两大派并称大乘「二大车轨」，时有辩论，但中观派认为唯识「心识实有」仍有微细法执，唯识究竟亦归于「识亦空」。详见[[唯识 Yogacara]]（Phase 3b 待建）。

## 与南传的关系

中观的「缘起性空」与南传[[缘起 Paticca Samuppada|缘起]]、[[三特性|无我]]在实相义上相通：都是破除自性实执、显缘起。中观是把原始佛教的缘起、无我原则，以哲学论证彻底普遍化（「一切法空」「法无我」）。南传内观亲证「无我、消融」，与中观的「空性现观」是同一实相的不同诠释。详见[[空性 Sunyata]]。
