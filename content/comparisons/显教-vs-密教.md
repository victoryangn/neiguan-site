# 显教 vs 密教
> 显教（Sūtrayāna/Exoteric）vs 密教/金刚乘（[[金刚乘 Vajrayana|Vajrayana/Tantra]]，Esoteric）——大乘佛教的两种形态。显教依经教渐修（因位道），密教依密续以佛果境界为道（果位道），主张即身成佛。二者**非对立**——密教建立在显教基础上加速，藏传「先显后密」是典型。

## 核心区分

| 维度 | 显教（大乘经教） | 密教（[[金刚乘 Vajrayana\|金刚乘]]） |
|------|------------------|---------------------------------------|
| **所依经典** | 经（Sūtra）：般若、法华、华严等 | 密续（Tantra）：时轮、胜乐、密集等 |
| **道的性质** | 因位道（从凡夫渐修趋向佛果） | **果位道**（以佛果境界为当下修行） |
| **核心方法** | [[六波罗蜜\|六度]]、[[止禅 Samatha\|止观]]、[[菩萨道 Bodhisattva\|菩萨行]] | [[本尊瑜伽]]、气脉明点、持咒、曼陀罗 |
| **成佛速度** | 三大阿僧祇劫 | **即身成佛**（一生成就） |
| **戒律** | [[五戒与戒律\|别解脱戒]]、菩萨戒 | 三昧耶戒（samaya） |
| **入门** | 皈依、发心、闻思修 | 须经**金刚上师灌顶**授权 |
| **师承** | 经教可自学 | 须具德上师口传、灌顶 |

## 显密关系：非对立，而是基础与加速

> ⚠️ 关键：密教**不否定显教**，而是建立在显教基础上。无显教基础（出离心、菩提心、[[空性 Sunyata|性空正见]]）的「密法」是危险的，甚至被视为非法。

### 先显后密

[[藏传佛教四大教派|藏传佛教]]（尤其[[宗喀巴 Tsongkhapa|格鲁派]]）严格遵循「**先显后密**」：

```
显教基础（必备）：出离心 → 菩提心 → 性空正见（[[中观 Madhyamaka\|中观]]）
        ↓ （通达后方入密）
密续修学：灌顶 → 生起次第（本尊瑜伽）→ 圆满次第（气脉明点，乐空不二）→ 即身成佛
```

格鲁派要求先修学十余年显教「五部大论」（[[中观 Madhyamaka|中观]]、般若、戒律、[[阿毗达磨 Abhidhamma|俱舍]]、因明），方可入密续——这正是「显为密基」的实践。

## 为何密教能「即身成佛」？

显教与密教所证的**佛果相同**，差异在**速度与方法**：

- 显教从「凡夫位」渐次修因（六度），须经漫长劫数积累。
- 密教「果位道」：直接以**佛果的清净境界**（本尊、坛城、清净见）作为当下所缘，转化染污身心为清净佛智——故能极大加速。
- 密续的气脉明点修法，能令心气入中脉、引生光明，配合空慧成「乐空不二」，是显教单修空性所无的殊胜方便。

> 但这「加速」有代价：须正见与戒律严格摄持，须经灌顶与具德上师指导——力量越大，越须 safeguards。无此基础的密法极易成歧途。

## 三乘的层级关系

佛教传统将声闻、缘觉、菩萨、密续组织为递进的「乘」：

```
声闻乘（求阿罗汉）→ 缘觉乘 → 菩萨乘（[[菩萨道 Bodhisattva\|大乘显教]]）→ 金刚乘（密教）
   共通：四圣谛、缘起、戒定慧（一切乘的地基）
```

> 藏传的「九乘」（宁玛）、「五道十地」等判教，皆将显密组织为递进次第——密续是建立在显教菩萨道之上的无上方便，而非脱离显教的另一回事。

## 常见误解

### ❌ 藏传佛教＝密教（不含显教）

错。藏传是**显密完整体系**：四大教派皆重显教（道次第、中观/唯识、戒律），密续是其上加速部分。格鲁派甚至先修十余年显教方入密。

### ❌ 密教不讲空性

正相反。空性正见是密乘的**绝对前提**——大手印、大圆满所证即是心性空性，与[[中观 Madhyamaka|中观]]一脉相承。无空性智慧的「密法」是执相的外道。
