# 往生论
> [[世亲 Vasubandhu|世亲]]所造《无量寿经优婆提舍愿生偈》（简称《往生论》，Sukhāvatīvyūhopadeśa），净土宗所依「三经一论」之**论**。以五念门系统建立净土修行，是印度大乘论师对净土法门的根本论述，[[昙鸾 Tanluan|昙鸾]]造《往生论注》释之。

## 核心含义

《往生论》是[[世亲 Vasubandhu|世亲]]所造的净土论典（优婆提舍，即论议/口诀）。论名「愿生偈」——以偈颂表达愿生西方净土之心，并长行释之。此论是印度大乘论师造的净土根本论，汉传净土宗列为「三经一论」之论。

> 世亲造《往生论》立「五念门」修净土行；[[昙鸾 Tanluan|昙鸾]]造《往生论注》释之，奠定他力本愿、易行道的理论基础。

## 核心义理：五念门

《往生论》以「**五念门**」系统组织净土修行：

| 念门 | 修法 |
|------|------|
| 礼拜门 | 恭敬礼拜阿弥陀佛 |
| 赞叹门 | 口称名号、赞叹佛德 |
| 作愿门 | 发愿往生净土 |
| 观察门 | 观察极乐世界二十九种庄严（佛/菩萨/国土） |
| 回向门 | 以所修功德回向一切众生同生净土 |

> 五念门含身（礼拜）、口（赞叹）、意（观察）三业，及愿、回向二心，是净土行的系统化组织——较后世「信愿行」三资粮更详尽。

## 在学派中的地位

- **三经一论之论**：汉传[[净土宗]]依「净土三经」加《往生论》，本论是唯一的「论」。
- **世亲净土观**：本论是印度大乘论师（世亲）对净土法门的根本论述，证明净土信仰在印度大乘已有根基。
- **昙鸾注**：[[昙鸾 Tanluan|昙鸾]]《往生论注》释本论，建立他力本愿、易行道，是净土宗理论源头。
