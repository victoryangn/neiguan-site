# 唯识 Yogacara
> Yogācāra（瑜伽行派/唯识宗），大乘两大哲学支柱之一（与[[中观 Madhyamaka|中观]]并立），主张「**万法唯识**」——一切现象皆心识（vijñāna）所变现，无心外实境（唯识无境）。又称唯心宗、法相宗（汉传）。它将[[阿毗达磨 Abhidhamma|阿毗达磨]]的心识分析推向极致，是大乘对「心如何认识世界」的精密解答。

## 核心含义

唯识的核心命题是「**三界唯心，万法唯识**」：我们经验到的整个外境世界（色声香味触法），并非离心独立实有，而是**心识变现的影像**。唯识并非否定现象，而是追溯其根源——一切现象的源头是心识。

### 唯识无境

> 凡夫以为有离心实存的客观外境；唯识指出，外境如梦中所见，皆是心识所现，故「唯识无境」。心外无实境，唯识所现。

### 八识——心识的精密结构

唯识在阿毗达磨六识基础上，开出**八识**体系：

| 识 | 巴/梵 | 功能 |
|----|-------|------|
| 前五识 | 眼耳鼻舌身 | 感官认识（仅了别，不分别） |
| 第六 | 意识（manovijñāna） | 思惟、分别、造作的主力 |
| 第七 | **末那识**（manas） | 恒审思量「我」，执阿赖耶为自我（我执之根） |
| 第八 | **阿赖耶识**（ālaya） | 藏识，含藏一切业力「种子」，为万法生起的根本所依 |

> 阿赖耶识如一座「业力仓库」，储藏无始以来所造的善恶业种子；种子遇缘现行，变现为身心与世界。末那识恒执阿赖耶为「我」，是一切我执的根源。这一模型把「[[业与轮回 Samsara|业力如何相续]]」「无我而轮回」的难题，作了精密解答。

### 三性与三无性

唯识以「**三性**」分析一切法的存在方式：

| 三性 | 内容 | 对应三无性 |
|------|------|------------|
| 遍计所执性 | 凡夫于依他起上妄执实有（如执绳为蛇） | 相无性（所执之相本无） |
| 依他起性 | 依因待缘而生（缘起的现象） | 生无性（无自然生） |
| 圆成实性 | 依他起上遣除遍计所显的真如 | 胜义无性（无妄执之性） |

### 转识成智

修行的目标是**转识成智**——将污染的八识转为清净的四智：

```
第八阿赖耶识 → 大圆镜智（如大圆镜，普照一切）
第七末那识   → 平等性智（视自他平等，破我执）
第六意识     → 妙观察智（善观诸法，无碍说法）
前五识       → 成所作智（起神通妙用，利益众生）
```

## 与中观的关系：大乘二大车轨

唯识与[[中观 Madhyamaka|中观]]并称大乘「二大车轨」，时有诤论：

| | 中观 | 唯识 |
|--|------|------|
| 破执次第 | 直破「法执」——一切法空、无自性 | 先破「外境」归于一心，再破「识」亦空 |
| 究竟义 | 一切法（含心识）皆空 | 识亦无自性，究竟归空（但方便安立「唯识」以破外境实执） |
| 诤论焦点 | 中观认为唯识执「心识实有」是微细法执 | 唯识认为中观「一切皆空」易堕断见，须以唯识为方便 |

> 中观派（尤其应成派）认为唯识「境空心有」仍残留法执，须进一步「识亦是空」方为究竟；唯识究竟义其实也承认识无自性，只是以「唯识」为对治外境实执的善巧方便。两派究竟同归空性，差异在方法论与所破的次第。

## 经典与论典

- 经典：[[解深密经|《解深密经》]]（唯识根本经）、《楞伽经》《厚严经》。
- 论典：传[[世亲 Vasubandhu|无著]]从弥勒菩萨受《**瑜伽师地论**》（百卷，唯识根本论）；无著《摄大乘论》；[[世亲 Vasubandhu|世亲]]《**唯识三十颂**》《唯识二十论》《辩中边论》。
- 汉传：玄奘、窥基依《成唯识论》（护法等十大论师释三十颂之集）创**法相宗**（慈恩宗）。

## 与阿毗达磨/内观的关系

唯识继承并深化了[[阿毗达磨 Abhidhamma|阿毗达磨]]的心识分析——八识是对六识的扩展，阿赖耶识是对「业力相续」的精密化。可视为法相分析的大乘进阶。南传内观观察心念的生灭、无我，与唯识「转识成智」「万法唯识」在「心为根本」的方向上一致，但诠释框架不同。
