# 金刚乘 Vajrayana
> Vajrayāna（金刚乘/密乘/真言乘），大乘佛教的密教化形态——约公元6–7世纪于印度兴起，以「**果位道**」（以佛果境界为当下修行）、密续（Tantra）为所依，结合本尊瑜伽、持咒、曼陀罗、气脉明点、灌顶等善巧方便，主张**即身成佛**。「金刚」（vajra）表坚固不坏、迅疾、究竟。

## 核心含义

金刚乘是[[大乘佛教 Mahayana|大乘]]的进一步发展，其独特处在于「**果位道**」（phala-yāna）：一般的修行是「从因位渐修」（凡夫逐步趋向佛果），而金刚乘直接以**佛果的清净境界**（本尊、坛城、清净见）作为当下的修行所缘，转化染污的身心为清净的佛智——故名「转位道」「果位道」，速度远超常途。

### 显密关系（重要）

> ⚠️ 金刚乘**不否定显教**，而是建立在显教基础上加速。格鲁派强调「**先显后密**」——须先通达[[中观 Madhyamaka|中观空性正见]]、修[[菩萨道 Bodhisattva|菩提心、六度]]，再入密续。

- 显教基础：出离心、菩提心、性空正见（[[空性 Sunyata]]）——密乘必备前提。
- 密续加持：本尊瑜伽、气脉明点、灌顶——加速成佛的善巧方便。
- 故藏传佛教是「**显密并重**」的完整体系，非「只有密咒」。

### 金刚乘的核心特征

| 特征 | 内容 |
|------|------|
| **果位道** | 以佛果清净境界为修行（本尊瑜伽） |
| **密续（Tantra）** | 所依经典，如《时轮续》《胜乐续》《密集续》《大日经》《金刚顶经》 |
| **本尊瑜伽** | 观想与本尊合一，转三业为本尊三密（见[[本尊瑜伽]]） |
| **气脉明点** | 无上瑜伽的生理-心性修法（见[[本尊瑜伽]]圆满次第） |
| **灌顶与三昧耶戒** | 须经金刚上师灌顶授权，守三昧耶戒 |
| **方便+智慧** | 大悲方便（方便道）与般若空慧（智慧）结合，乐空不二 |

## 生起次第与圆满次第

密续修法的两阶段（详见[[本尊瑜伽]]）：

```
生起次第（utpattikrama）—— 观想本尊、曼陀罗、持咒，净除凡夫实执，成就「清净见」
        ↓
圆满次第（saṃpannakrama）—— 修气脉明点，收摄入中脉，现证俱生大乐与空性不二（乐空不二）
```

## 金刚乘 vs 显教大乘

| | [[大乘佛教 Mahayana\|显教大乘]] | 金刚乘 |
|--|--------------------------------|--------|
| 道的性质 | 因位道（从凡夫渐修） | 果位道（以佛果为道） |
| 成佛速度 | 三大阿僧祇劫 | **即身成佛**（一生成就） |
| 所依 | 经（Sūtra） | 密续（Tantra） |
| 方法 | 六度、止观 | 本尊瑜伽、气脉明点、咒、曼陀罗 |
| 前提 | 菩提心、空性正见 | 须先具显教基础 + 灌顶 + 上师 |

## 传播与保存

- **藏传佛教**：金刚乘最完整的传承所在。四大教派（宁玛、噶举、萨迦、格鲁）皆修显密，密续体系完备。详见[[藏传佛教四大教派]]。
- **汉传密宗（唐密）**：唐·善无畏、金刚智、不空传入，依《大日经》《金刚顶经》。后渐衰。
- **东密（日本真言宗）**：空海从唐传入，至今传承不绝。
- **南传/上座部**：**无密乘**。本 Wiki 基点的[[内观 Vipassana|内观]]属纯显/解脱道，与密乘无涉。

## 常见误解

### ❌ 藏传佛教＝金刚乘＝只有密咒

藏传佛教是**显密完整体系**：四大教派皆重视显教（[[中观 Madhyamaka|中观]]、[[唯识 Yogacara|唯识]]、道次第、戒律），密续是其上加速成佛的部分。格鲁派甚至先修十余年显教（五部大论）方入密续。

### ❌ 金刚乘不讲空性

正相反。空性正见是密乘的**绝对前提**——无空性智慧的「密法」易堕执相。大手印、大圆满等无上法门，所证即是[[空性 Sunyata|心性空性]]，与[[中观 Madhyamaka|中观]]一脉相承。
