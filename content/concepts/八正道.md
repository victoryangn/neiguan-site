# 八正道 (Ariya Atthangika Magga)
> 佛陀教导的灭苦之道，分为戒、定、慧三学，必须是"如实"(yatha-bhutam)的亲身体验。

## 核心含义

八正道是 [[四圣谛]] 中的道谛——导向苦灭的实践道路。这八个道支不是孤立的条目，而是一个有机的整体，分为三个训练：

### 戒学 (Sila) — 道德的基础

1. **正语 (Samma Vaca)**
   - 不妄语——不说谎、不欺骗
   - 不两舌——不挑拨离间
   - 不恶口——不说粗恶的话
   - 不绮语——不说无意义的闲话

2. **正业 (Samma Kammanta)**
   - 不杀生——不伤害任何生命
   - 不偷盗——不取未给予之物
   - 不邪淫——不当的性行为

3. **正命 (Samma Ajiva)**
   - 以正当的方式谋生
   - 不从事伤害众生的职业（如贩卖武器、毒品、酒类、屠宰等）

戒学是修行的基础。没有道德的基础，心不可能安定；心不安定，就不可能开发真正的智慧。在内观课程中，学员在前九天持守五戒（或八戒），为深入修行创造清净的环境。

### 定学 (Samadhi) — 专注的训练

4. **正精进 (Samma Vayama)**
   - 防止未生起的不善心生起
   - 去除已生起的不善心
   - 培养未生起的善心
   - 维持已生起的善心

5. **正念 (Samma Sati)**
   - 对身体、感受、心、法保持觉知
   - 即是 [[四念住 Satipatthana]] 的修习
   - 不仅仅知道现象的存在，更要彻知其无常本质（Sampajanna）

6. **正定 (Samma Samadhi)**
   - 心一境性——心的统一和专注
   - 通过 [[观息法 Anapana]] 培养基础定力
   - 通过 [[内观 Vipassana]] 发展更深的定力

### 慧学 (Panna) — 智慧的开发

7. **正思惟 (Samma Sankappa)**
   - 出离思惟——不执著于感官享乐
   -无瞋思惟——慈爱、不怀恶意
   - 无害思惟——不伤害众生

8. **正见 (Samma Ditthi)**
   - 了知 [[四圣谛]] 的实相
   - 亲身体验 [[三特性]]（无常、苦、无我）
   - 不同于智力上的理解

### "如实"的重要性

八正道强调的是"如实"（Yatha-bhutam）——如事物本来的样子。智慧不是从书本上得来的，不是从思考中得来的，而是从直接的体验中得来的。

> 只有你自己亲身体验到的，才是真正的智慧。听来的、读来的、想来的，都只是表面的知识（Suta-maya panna），不是真正的智慧（Bhavana-maya panna）。

## 经典依据

> "何为正见？诸比丘，如实了知苦，如实了知苦集，如实了知苦灭，如实了知苦灭之道——这称为正见。"

> "何为正思惟？出离思惟、无瞋思惟、无害思惟——这称为正思惟。"

——[[四念住开示课程全文]]

> "八正道不是离开这个世界去修行的道路，而是在这个世界中，面对生活的实相，一步一步走向解脱的道路。戒定慧三学是同时发展的，不是先完成一个再做另一个。"

——[[内观十日课程开示集要]] 第9天开示

## 修行实践

### 在内观课程中的体现

| 道支 | 在课程中的实践 |
|------|---------------|
| 正语 | 课程期间保持静默（Noble Silence） |
| 正业 | 遵守五戒/八戒 |
| 正命 | 课程期间放下世俗事务 |
| 正精进 | 持续精进修行，不懈怠不放逸 |
| 正念 | 时时觉知身体感受，保持 Sampajanna |
| 正定 | 以 Anapana 和 Vipassana 培养定力 |
| 正思惟 | 培养出离心、慈爱、无害心 |
| 正见 | 亲身体验无常、苦、无我 |

### 戒定慧的循环发展

三者不是线性的先后关系，而是互相促进的：
- 持戒使心安住 → 定力提升
- 定力提升 → 能观察实相 → 智慧增长
- 智慧增长 → 更清楚地看到持戒的重要性 → 戒行更清净
- 如此循环，螺旋上升
