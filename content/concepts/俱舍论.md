# 俱舍论
> [[世亲 Vasubandhu|世亲]]早期（部派期）所造《阿毗达磨俱舍论》（Abhidharmakośa-bhāṣya），说一切有部论典的巅峰，以八品系统总结部派佛教的宇宙、心识与修行阶位，是印度部派佛教法相学的最高成就。

## 核心含义

《俱舍论》是[[世亲 Vasubandhu|世亲]]尚在说一切有部（兼采经量部）时约公元4世纪所造。论名「俱舍」（kośa，藏/容器）意为含藏、摄持阿毗达磨一切义理之库——世亲于归敬序中表明此论总摄阿毗达磨胜义，故名「俱舍」。它虽属部派，然其法相分析的严密完整，使大乘[[唯识 Yogacara|唯识]]、藏传格鲁派皆奉为根本教材。

全论分**本颂**（六百颂，世亲造）与**长行释**（世亲自释），另有众贤造《顺正理论》反驳之（护持有部立场）。

## 结构与要义

八品结构，前二品明「法体」，次三品明「流转」，后三品明「还灭」：

| 品 | 主题 | 要义 |
|----|------|------|
| 分别界品（一） | 三界、十八界 | 宇宙要素分类 |
| 分别根品（二） | 二十二根、心所 | 认识与心理功能 |
| 分别世间品（三） | 三界、六道、劫 | 世界结构、[[业与轮回 Samsara|轮回]] |
| 分别业品（四） | 业的分类、表无表业 | [[业与行 Sankhara|业力]]法则 |
| 分别随眠品（五） | 九十八随眠、六根本烦恼 | 烦恼与系缚 |
| 分别贤圣品（六） | 七贤、四向四果 | [[解脱阶段|修行阶位]] |
| 分别智品（七） | 十智 | 智慧类别 |
| 分别定品（八） | 四禅、八定 | [[禅那 Jhana|禅定]]体系 |

> 另有第九「破执我品」，破犊子部等所执「补特伽罗」实我，归宗[[五蕴|无我]]。

> 「世间·业·随眠」三品讲流转轮回之因，「贤圣·智·定」三品讲还灭解脱之因——与南传[[清净道论 Visuddhimagga|清净道论]]的「流转/还灭」框架异曲同工，二者皆为佛教「法相 + 次第」的体系化典范。

## 在学派中的地位

- **部派论典巅峰**：统摄说一切有部七论精华，兼采经量部批判，是部派法相学集大成。
- **跨部派对照**：与南传[[阿毗达磨 Abhidhamma|阿毗达磨]]同属「法相分析」传统（南传是分别说系，俱舍是有部），二者构成研究早期佛教心识论的双重视角。
- **大乘沿用**：世亲转入大乘后，[[唯识 Yogacara|唯识]]的八识、种子等义理直接继承自俱舍的法相分析。
- **汉藏所重**：真谛先译（「旧译」《阿毗达磨俱舍释论》），玄奘重译（「新译」《俱舍论》）；藏传格鲁派列为法相根本教材。
