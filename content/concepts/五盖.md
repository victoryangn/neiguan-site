# 五盖

**Panca Nivarana** — 五种禅修障碍，如同盖子一般遮蔽心性，阻碍修行者获得定力和智慧。它们是修行路上最直接、最常遇到的敌人。认识并克服五盖，是[[戒定慧三学]]中"定"和"慧"修习的关键。

---

## 五种禅修障碍

### 1. 贪爱 — Kamacchanda

**感官欲望** — 对愉悦感受的渴求和执着。

- 表现形式：坐禅时不断回想过去的享受，幻想未来的快乐
- 根源：对[[感受 Vedana|乐受（Sukha vedana）]]产生贪爱反应
- 在内观中：对微细的震动、电流感等愉悦感受产生执着，不愿放手
- 克服方法：观察贪爱本身的生灭，了知一切愉悦感受都是[[三特性|无常]]

### 2. 瞋恨 — Vyapada

**厌恶和愤怒** — 对不愉悦事物的排斥。

- 表现形式：对疼痛的抗拒、对环境的抱怨、对他人的不满
- 根源：对[[感受 Vedana|苦受（Dukkha vedana）]]产生瞋恨反应
- 在内观中：对强烈的疼痛、麻木等不愉悦感受产生厌恶，想要逃避
- 克服方法：以[[平等心 Upekkha]]观察瞋恨本身，不与之认同，了知它也是无常的

### 3. 昏沉 — Thina-middha

**昏沉和睡眠** — 心的迟钝和萎靡。

- 表现形式：坐禅时打瞌睡、意识模糊、缺乏清明
- 包括：Thina（心所的昏沉）和 Middha（心理的睡眠）
- 在内观中：尤其容易在饭后、长时间禅坐后出现
- 克服方法：加强精进力（Viriya），挺直身体，睁大眼睛，做些经行
- 与[[五力]]的关联：精进和定失衡时容易发生

### 4. 掉悔 — Uddhacca-kukkucca

**散乱和后悔** — 心的躁动不安。

- 表现形式：
  - **掉举（Uddhacca）**：心不断游走，无法安住当下
  - **后悔（Kukkucca）**：反复回想过去的错误，内心不安
- 在内观中：心不断跑掉，无法持续观察感受
- 克服方法：回到呼吸，回到身体的感受，耐心地一次次拉回觉知
- 与[[五力]]的关联：精进过强而定不足时容易发生

### 5. 怀疑 — Vicikiccha

**对法和修行的疑惑** — 动摇修行信心的内在质疑。

- 表现形式：
  - "这个方法真的有效吗？"
  - "我真的能修行成功吗？"
  - "老师教的对吗？"
- 这是最危险的障碍之一，因为它能让人完全放弃修行
- 根源：缺乏信（Saddha）和慧（Panna）的平衡
- 克服方法：以亲身体验来验证，即使是微小的进步也给予肯定

## 五盖的运作机制

五盖是轮回（Samsara）的维系力量。它们通过[[感受 Vedana|感受]]来运作：

```
六根接触 → 感受 → 五盖生起 → 贪爱/瞋恨 → 轮回持续

      ↻ 唯有以平等心观察感受，才能打断这个循环
```

五盖不是外来的敌人，而是我们自己内心不净[[烦恼]]的显现。它们从无始劫以来就伴随着我们，但在修行中，我们终于有了面对它们、超越它们的方法。

---

## 以内观克服五盖

[[葛印卡 S.N. Goenka]]老师教导的方法是：

1. **觉察**：首先认出五盖的生起——贪爱出现了？瞋恨出现了？昏沉来了？
2. **不逃避**：不试图赶走它们，也不被它们带走
3. **观察**：以[[平等心 Upekkha]]观察这些障碍本身，观察它们在身体上的感受
4. **了知无常**：理解"它生起了，它也必将灭去"（Anicca）
5. **自然消散**：当平等心足够强大时，五盖自然消散

正如佛陀所说：黑暗不能被驱逐，但当光明到来时，黑暗自然消失。[[七菩提分]]就是这光明——当觉支成熟时，五盖自然消退。

## 五盖与五力

五力是五盖的直接对治：

| 五盖 | 对治的五力 |
|------|-----------|
| 贪爱（Kamacchanda）| 慧（Panna）— 智慧了知无常，不再执着 |
| 瞋恨（Vyapada）| 定（Samadhi）— 心安定则不生瞋恨 |
| 昏沉（Thina-middha）| 精进（Viriya）| 精进对治懈怠 |
| 掉悔（Uddhacca-kukkucca）| 定（Samadhi）| 专注对治散乱 |
| 怀疑（Vicikiccha）| 信（Saddha）— 信心对治疑虑 |
